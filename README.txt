Unity 6000.0.59f2

A simple fighting game with rollback netcode. It works only on a local network. Since the lag on a local network is so small, you can artificially add lag to see the rollback in action using the buttons on screen.

Link to itch.io and .exe: https://dvi-71.itch.io/capsule-fighter

Controls:
A/D move
W jump
S crouch
SPACE attack

(The project was done without proper version control, so it is just a single commit)
